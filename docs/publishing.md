# Publishing findings on ryanclinton.uk

Ryan wants SignalSearchYoke's findings to appear at
ryanclinton.uk/astrophotography/signalsearch/, posted the way telescopeyoke
posts to the diary. This is a request to use the site's existing inbox for
that. SignalSearchYoke builds nothing of its own for hosting or publishing.

## What SignalSearchYoke would send

Each post is one finding, written when there is one to report. The first two
would be:

- the comparison with turboSETI and BLISS on the 2017 KIC8462852 session;
- the second session (HIP17147, 2016), which failed its false-candidate
  limit. This is reported as a failure, plainly.

Each post contains:
- text, with every number read from the project's committed records and
  checked against them before sending;
- a table or a figure where one helps;
- credit to Breakthrough Listen for the data, with no use of their logo or
  name as an endorsement.

The repository is private, so no post links into it.

## What SignalSearchYoke needs from the site

- the inbox's post format, and how a post is sent there;
- anything the site's checks need from a post;
- how the voice should go, if it differs from the diary's.

SignalSearchYoke writes to that format. Everything about the site itself,
its pages, checks, build and server, stays as the site already does it.
