# Security

To report a vulnerability, or something in this repository or its history
that should not be public (a credential, a private address), use GitHub's
private vulnerability reporting: the repository's Security tab, "Report a
vulnerability". Please don't open a public issue for it.

The software reads Breakthrough Listen's public archive over HTTPS and
writes only under its data folder (`data/`, or `SSY_DATA`). It runs no
server and holds no credentials.
